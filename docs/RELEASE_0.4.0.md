# EBOOK 0.4.0 · 漫画来了
> 探索页新增「漫画」：高分神作和名作推荐，搜索时漫画和小说一起出来，加入书架、阅读体验和轻小说一样；外文漫画的书名、简介、章节名自动翻成中文

## 本次更新

- **漫画**：探索页「轻小说 / 漫画」切换，漫画和轻小说同一套题材世界（奇幻、校园、科幻、恋爱、悬疑）和瀑布流书墙，不分源、混在一起。
  - 内置 21 个漫画源（来自开源项目 Venera 的源仓库，成人站不收），默认打开 10 个。插件页「漫画源」里可以开关、改设置，点「测一遍」，在你的网络下能用的会自动打开。
  - 漫画页最上面是「高分神作」光盘架：血之辙、再见绘梨、蓦然回首、浪客行、怪物、冥王、20世纪少年、虫师、3月的狮子、少女终末旅行、地。、来自深渊、晚安布布、乒乓、宝石之国、剑风传奇、火之鸟、恶之华、炎拳、海街diary、棋魂、镖人，每部附一句推荐语。
  - 书墙最前面先放大家都听过的名作：咒术回战、东京喰种、海贼王、鬼灭之刃、进击的巨人、电锯人、间谍过家家、葬送的芙莉莲等 43 部，书名一律显示简体。第一次打开要几十秒找齐，之后直接出来。
- **搜索**：搜一个名字，漫画和小说一起列出来；几个源里的同一部漫画合成一条，详情里可以换源。
- **阅读和书架**：漫画阅读器和小说阅读器同一套界面、手势和面板（目录、进度、书签、阅读方式、纸张），支持条漫、翻页、从右往左；加入书架后书架和首页「继续阅读」显示看到第几话第几张，点开接着看；账户导入导出带上漫画。
- **外文漫画翻成中文**：MangaDex 这类英文、日文源的书名、简介、标签、章节名自动翻译，原名留在「又名」里；MangaDex 每一话优先用中文汉化版。只翻文字，图里的对白不翻。插件页可以关掉。
- **外观「跟随系统」**：插件页「外观」多了第三档，手机、电脑切深色模式时 EBOOK 跟着变；原来选的浅色 / 深色不受影响。
- **iPhone 适配**：在 iPhone SE、16 Pro、16 Pro Max 模拟器上把首页、探索、漫画详情、阅读器、书架、搜索、插件逐屏走查截图；修了 SE 等小屏上题材切换条最右边的「谜」被切掉一半。
- **安全**：漫画源的脚本在隔离的沙箱里运行，碰不到书架、账户和本机文件，也访问不了本机和局域网；Windows、安卓、iPhone 三端都实测过：沙箱里调不动原生功能。

## 下载与升级

- Windows 10 / 11：`EBOOK_0.4.0_x64-setup.exe`，退出旧版后覆盖安装。
- 安卓：`EBOOK_0.4.0.apk`，沿用原来的签名，可覆盖安装。
- iPhone：`EBOOK_0.4.0_ios-unsigned.ipa`，用 SideStore 签名后覆盖安装（不要先卸载旧版，书架才能保留）。

## 已知情况

- 漫画源是第三方网站，能不能打开取决于你的网络和网站当时的状态；连不上的源点「测一遍」会自动关掉。
- 翻译用的是微软 Edge 浏览器内置翻译的免费接口，哪天不能用了会显示原文，不影响看漫画。
