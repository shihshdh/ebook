产品提交：`3cc3132b6061d81dd08aecf5ef598732583f7235`。本记录补充不改变客户端资源。

本次重点修复漫画书页封面与光盘显示。封面不再被后台拼贴的慢请求堵住；可见区域优先，滚入视口立即唤醒排队任务，慢图床隔离，备用源错峰并发。组件独立持有图片地址，缓存淘汰不再撤销仍显示的地址。失败自动重试，旧版过度屏蔽源的记录不会继续阻止新版取图。

另复现并修复：异步结果替换同数量的光盘列表后，新 DOM 没有重新计算位置和尺寸，5 张盘宽均为 0。修复后 Chromium、WebKit 均为 174px；同时回收旧节点动画信息。

漫画书单增加账户内缓存，先展示再更新；分页每个源完成即追加，名作查找不再阻塞书单完成状态。隐藏小说/漫画页面退出布局，漫画源开关统一为 51×31px，并保留额外触控区域。

开屏改为约 2.8 秒：渐显、书页轻展、名称显现、柔和淡出。仅使用 opacity/transform，仍支持点击跳过与减少动态效果。
