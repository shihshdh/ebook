# EBOOK 0.3.15 · 手机端流畅度全面优化、插图版下载修复
> 手机端全面提速：切页、滚动、搜索、打开书详情、换世界更顺，开屏不再闪；底栏滑块更圆润；修复插图重制版下载

## 本次更新

- **插图重制版下载修复**：上游把插图重制版搬到了 mojimoon/wenku8-epub，现在按索引里标明的仓库下载，恢复插图版下载；地址失效时不再误提示「换个网络」。
- **切页**：去过的页面留在后台，空闲时提前把还没去过的页（探索、搜索、书架、插件，导入过订阅源时还有订阅）渲染、排版好，第一次点进去不用现做；切页时不再整页重算样式。
- **探索页滚动**：书名、摘句用的衬线字提前分批下好再上屏，往下翻新一页时不再顿一下；没有真封面的书不再显示破图。
- **搜索打字**：结果分帧出现、已有的行原地保留，敲字时输入框跟手。
- **打开书详情**：按下书的那一刻就开始准备，面板滑入更顺；可以往下拖动关闭。
- **探索页换世界**：五个世界用到的字体在空闲时提前备好，切换时不再卡一下。
- **开屏**：退场时不再把首页盖回去闪一下；标志描线、金线展开、手写显现不再停住再跳；书库整理更快。
- **首页**：唱片停稳后的匀速自转交给系统合成线程，静置时几乎不占用处理器，更省电。
- **手感**：阅读器翻页轻拨就翻、书页完全跟手；光盘可以甩动；触屏按下有反馈，悬停状态不再卡住。
- **底栏滑块**：两头正圆的胶囊形状，切换时的液态动画完整播放。
- **生成封面**：没有封面的书，生成封面改在后台线程绘制，不再占用界面线程。

所有动画保持原有时长和速度，没有为了「快」把动画调快。首页长距离滚动在部分手机上仍可能偶有掉帧。
