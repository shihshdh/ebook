# EBOOK 0.3.16 · 修复书架页偏移、检查更新更稳
> 修复书架页被章节名撑宽、整页横向偏移；检查更新可以取消，下载慢或失败时可改用浏览器下载

## 本次更新

- **书架页偏移**：「继续阅读」的章节名很长时，卡片会被撑得比屏幕还宽，整页在手机上可能被横向推偏。现在长章节名截成省略号，页面内容横向不会再超出屏幕。
- **检查更新更稳**：
  - 确认下载到的是完整安装包才显示 100%；某条线路下到的不对时进度回到开头、自动换线路，不再停在 100% 不动。
  - 分步显示：下载、校验、打开安装器。
  - 下载中可以取消。
  - 下了 25 秒还没好，或者没下成，会给出「用浏览器下载」的链接，下好后手动安装即可。

这一版的「检查更新」改进要从 0.3.16 开始才生效：0.3.15 及更早的版本更新到 0.3.16 时仍是旧的更新流程，如果卡住，可以从下面的链接直接下载安装。

## 下载与升级

- Windows 10 / 11：`EBOOK_0.3.16_x64-setup.exe`，退出旧版后覆盖安装。
- 安卓：`EBOOK_0.3.16.apk`，沿用上一公开版签名，可覆盖安装。
- README 下载链接及客户端 `latest.json` 同步更新，下载完成后校验 SHA-256。

## 验证

- 规则引擎 96/96、内置源与搜索池等测试 19/19 通过。
- 书架页用很长的章节名复现：修复前页面宽 465px（屏幕 390px），修复后与屏幕同宽、章节名显示省略号；手机、电脑宽度各页截图逐像素对比，其余画面不变。
- 更新卡片的连接中、取消、下得慢、没下成四种状态在网页版上模拟验证；安卓、Windows 真机上的完整更新流程未实测。
