# EBOOK 0.3.17 · 手机端换上 iOS 液态玻璃界面（iPhone / 安卓）
> 手机界面按 iOS 设计逻辑重做：新配色和尺寸、可拖动的玻璃标签栏、「图书」式阅读器菜单、特效全部回归、系统触感

这是 iPhone 版的第一个正式版。iPhone 和安卓用的是同一套新界面，按 Apple 的 iOS 26 / 27 设计规范（液态玻璃）来做；电脑版这次没有变化。

## 本次更新

- **配色和尺寸**：按 iOS 的语义色重排——白底（深色是纯黑）、浅灰分组卡片、四级文字色，全 App 只用一个金色作强调，小字对比度都在 4.5:1 以上。字号、触控区、页边距、圆角统一，页面更紧凑。
- **液态玻璃只给功能层**：标签栏、悬浮按钮、书籍详情面板、提示条、阅读器工具栏用毛玻璃；页面里的内容卡片改成实色。iPhone 上打开「降低透明度」「增强对比度」后，玻璃会换成实色、文字加深。
- **新标签栏**：
  - 浮动的玻璃胶囊，搜索单独放在右边一颗圆钮里。
  - 手指按住时，选中块会浮起成放大透镜，外圈有自然的色散。
  - 整条都可以拖：透镜跟着手指走、按速度拉伸，松手后像果冻一样回弹，落到最近的那格，每跨过一格轻震一下。
  - 点当前格回到页面顶部。
- **阅读器菜单（参照 iPhone「图书」）**：左上返回圆钮，右上搜索和书签合成一组；底部是玻璃 dock，目录、进度、字体、纸张面板浮在 dock 上方；收起时右下角留一颗小菜单钮。进度条拖过章节时轻震。
- **书籍详情**：四边内缩的浮动面板，下拉关闭时遮罩跟着变淡。首页「继续读」遇到长书名时，按钮不再撑出屏幕。
- **特效全部回归**：
  - 手机上被关掉的书页之河、光盘自转、瀑布流翻页、世界切换推拉镜头都恢复了。
  - 搜索页的棱镜碎玻璃墙在手机上也打开了：进入画面时自己扫一遍光，手指按住拖动时光跟着手走。
  - 打开书改成封面原地放大的转场，阅读器同时开始加载。
  - 偶尔一次掉帧不再永久降低画质。
- **触感**：用系统原生触感——iPhone 是 Taptic Engine，安卓是系统定义的语义触感。切换类操作是轻「嗒」，成功和失败各有不同的触感，跟随系统设置。
- **弹出键盘时**，底栏会自动让开。

## 下载与升级

- **iPhone**：`EBOOK_0.3.17_ios-unsigned.ipa`，用 SideStore 导入安装（步骤见仓库首页「iPhone 安装」）。之前装过预发布版（0.3.16-ios.N）的，用同一个 Apple 账号直接覆盖安装，书架和阅读记录保留。
- **安卓**：`EBOOK_0.3.17.apk`，沿用原来的正式签名，覆盖安装即可。旧版里点「检查更新」也能直接装。
- **Windows**：这一版没有 Windows 安装包。电脑版界面没有变化，继续用 0.3.16。
