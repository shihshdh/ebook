# EBOOK 0.3.17 · 安卓换上 iPhone 同款液态玻璃界面
> 手机界面按 iOS 设计逻辑重做：新配色和尺寸、可拖动的玻璃标签栏、「图书」式阅读器菜单、特效全部回归、系统触感

## 本次更新（安卓）

和 iPhone 预发布版 0.3.16-ios.5 同一套设计，安卓也换上了：

- **配色和尺寸**：按 iOS 的语义色重排——白底（深色是纯黑）、浅灰分组卡片、四级文字色，全 App 只用一个金色作强调，小字对比度都在 4.5:1 以上。字号、触控区、页边距、圆角统一，页面更紧凑。
- **液态玻璃只给功能层**：标签栏、悬浮按钮、书籍详情面板、提示条、阅读器工具栏用毛玻璃；页面里的内容卡片改成实色。
- **新标签栏**：
  - 浮动的玻璃胶囊，搜索单独放在右边一颗圆钮里。
  - 手指按住时，选中块会浮起成放大透镜，外圈有自然的色散。
  - 整条都可以拖：透镜跟着手指走、按速度拉伸，松手后像果冻一样回弹，落到最近的那格。
  - 点当前格回到页面顶部。
- **阅读器菜单（参照 iPhone「图书」）**：左上返回圆钮，右上搜索和书签合成一组；底部是玻璃 dock，面板浮在 dock 上方；收起时右下角留一颗小菜单钮。进度条拖过章节时轻震。
- **书籍详情**：浮动面板，下拉关闭时遮罩跟着变淡。首页「继续读」遇到长书名时，按钮不再撑出屏幕。
- **特效**：
  - 搜索页的棱镜碎玻璃墙在手机上也开了：进入画面时自己扫一遍光，手指按住拖动时光跟着手走。
  - 打开书改成封面原地放大的转场，阅读器同时开始加载。
  - 偶尔一次掉帧不再永久降低画质，下次打开会重新按手机性能起步。
- **触感**：改用安卓系统定义的语义触感——切换类操作是轻「嗒」，成功和失败各有不同的触感，跟随系统「触摸反馈」开关。
- **弹出键盘时**，底栏会自动让开。

## 下载与升级

- 安卓：`EBOOK_0.3.17.apk`，沿用原来的正式签名，覆盖安装即可，书架和阅读记录保留。旧版里点「检查更新」也能直接装。
- Windows：这一版没有 Windows 安装包。电脑版界面没有变化，继续用 0.3.16。
- iPhone：在 SideStore 里更新 0.3.16-ios.5 预发布版（同一套界面）。
