# EBOOK 0.3.17 · iPhone 正式版，手机界面更新
> 手机界面重新整理，标签栏和阅读器菜单重新布局；手机上恢复全部动效；改用系统触感

iPhone 版从这一版起转为正式版，和安卓用同一个版本号。电脑版这次没有变化。

## 更新内容

手机（iPhone、安卓）：

- 配色、字号、间距按 iOS 的规范重新整理；页面里的卡片改成实色，标签栏、按钮、面板这类控件用毛玻璃。
- 标签栏：搜索移到右侧单独的按钮；按住标签栏可以左右拖动切换；点当前那格回到页面顶部。
- 阅读器菜单重新布局：返回、搜索、书签在顶部，目录、进度、笔记、字体、纸张在底部；收起时右下角留一个菜单按钮。
- 书籍详情改成浮动面板，可以下拉关闭。
- 恢复了之前在手机上关掉的动效：首页书页之河、光盘自转、瀑布流翻页、世界切换、搜索页棱镜墙；打开书改成从封面放大进入。
- 偶尔掉一次帧不会再永久降低画质。
- 触感改用系统原生的（iPhone 是 Taptic Engine，安卓是系统触感），跟随系统设置。
- 修复：首页「继续读」遇到长书名时撑出屏幕；弹出键盘时底栏挡住输入框。

## 下载与升级

- **iPhone**：`EBOOK_0.3.17_ios-unsigned.ipa`，用 SideStore 导入安装（步骤见仓库首页「iPhone 安装」）。之前装过预发布版（0.3.16-ios.N）的，用同一个 Apple 账号直接覆盖安装，书架和阅读记录保留。
- **安卓**：`EBOOK_0.3.17.apk`，沿用原来的正式签名，覆盖安装即可。旧版里点「检查更新」也能直接装。
- **Windows**：这一版没有 Windows 安装包，继续用 0.3.16。
