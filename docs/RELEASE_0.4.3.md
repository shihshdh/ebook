# EBOOK 0.4.3 · 连续翻页与玻璃滑块优化
> 优化漫画预加载，翻页与跨话保留已显示画面；适配 iPhone 16 Pro 详情圆角并改进玻璃滑块。

- 漫画手机前向缓冲四张，桌面六张，当前页优先，最多同时三张；快速跳页会停止等待旧任务，反向阅读随方向调整缓冲。
- 翻页图片先加载和解码，保留相邻页面节点；目标页未就绪时保留当前图并显示准备状态，避免露出黑底。双页会等待两张都就绪。
- 接近一话末尾时预热下一话的目录和首图；跨话保留原图直到新图显示，并隔离旧回调，避免快速连翻后跳章的偶发黑帧。
- 限制图片缓存窗口并及时释放页面地址；阅读进度与书签以实际显示的页为准。
- iPhone 详情弹层在底部安全区上方结束，圆角不再紧贴屏幕物理边缘；同时调整高度、横屏和长目录的底部间距。
- 保留玻璃底栏与按住拖动的玻璃透镜，减小过度膨胀、放大与彩边，优化跟手和回弹；修复滑块水平偏移、取消拖动及标签数量变化时的落位；为 WebKit 动画完成通知延迟增加收尾保障，及时释放玻璃层。

保留账户、书架、阅读进度和自定义源。iPhone IPA 仍需自行签名；源站波动仍会影响尚未缓冲的图片加载时间。
