# EBOOK 0.4.1 发布验收

产品源码：`325ebfd`；iPhone 构建与严格巡检：[GitHub Actions 39098459237](https://github.com/shihshdh/ebook/actions/runs/39098459237)。

## 功能与升级

- 随包漫画源 38 个，新账户默认开 24 个。真实 0.4.0 数据升级，在删除 Komiic 的测试账户中得到 37 个源：新增站点补入、删除不恢复、停用不改、自定义域名与 Cookie 保留。浏览器隔离账户和 Windows 正式程序均通过。
- 正文首图在详情页预取；只缓存即将阅读的一张，最多 2 张、每张 4MB、60 秒过期。预取图只请求一次，阅读器自己创建和释放 URL。
- 后台详情预取改为真正逐本等待，漫画页面不在前台时停止继续发起，避免阅读时争抢主线程和网络。
- 图标为用户选定的陶红 B 书签，开屏为书签轻提 1400ms，减少动态为 500ms。两方向、浅/深/跟随系统、键盘/点按跳过和会话只播一次均已复验。

## 实测与边界

| 环境 / 路径 | 结果 |
|---|---|
| 浏览器生产 UI + Node 模拟原生 HTTP，首图预取夹具 | 最终轮约 103ms；首图请求 1 次 |
| Windows 正式 exe + 真实 Tauri HTTP，首图预取夹具 | 最终轮约 94ms；首图请求 1 次 |
| Windows 最终轮《血之辙》Komiic，暖详情缓存 | 详情约 154ms，进入阅读器到第一图约 2220ms |
| 浏览器最终轮《血之辙》Komiic | 详情约 1026ms，首图约 985ms |
| 安卓固定 2400×3400 / 约 960KB 图，网络延迟 80ms、CPU 4倍降速 | Worker 版条漫 p95 33.3ms、翻页 16.7ms；最长分别 100/50ms |
| 同机启动三轮交替对照，手机 UI、CPU 4倍降速 | 6秒窗口主线程阻塞均值约 1152→905ms，约减少21% |

不能宣称零长帧或所有源都秒开：早一轮 Windows 在线同一源首图曾等约 19.7秒，真实源速度受网络、地区、站点限流和图像大小影响。安卓对照最早一轮混有模拟器冷启动，不能把全部差值归因于解码 Worker。书签动画只动合成属性，但整页启动压力测试仍有超过33ms的主线程帧。

安卓额外的升级/在线验收曾因模拟器整个进程退出而中断，没有记成通过；升级及在线链路随后在隔离浏览器和 Windows 原生程序验证。浏览器模拟原生 HTTP 不代表 Android/iPhone 原生栈速度。

- Android：versionName 0.4.1 / versionCode 18；签名与 0.4.0 一致，证书 SHA-256 为 `ae240e84b49ae8f8b64bbea8374148e9af334a5f010a71e381c26e1a4ab09cf4`。包内 103 个前端文件与最终 dist 逐字节一致。
- iPhone：0.4.1 / build 30，arm64 真机 Release、最低 iOS15，未签名 IPA。97 个前端文件逐字节一致；其余6个文本文件仅 LF/CRLF/CRCRLF 换行差异，实际字节差异已逐项检查。IPA SHA-256 与 CI 生成清单一致。
- 原生安装包测试不等于每台真实设备都验过；iPhone 通过 macOS runner 的真实 iOS 模拟器检查。未对用户设备执行安装或修改签名方式。
