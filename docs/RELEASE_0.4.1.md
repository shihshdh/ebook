# EBOOK 0.4.1 · 新书签图标与开屏，更多漫画源
> 新书签图标和陶红开屏；漫画源扩充、旧账户自动补源、详情首图预取与阅读流畅度优化

- 应用图标采用陶红与浅白书签，Windows、安卓和 iPhone 同步；开屏改为 1.4 秒书签轻提，支持跳过和减少动态效果。
- 随包漫画源从 21 个增至 38 个，新账户默认开启 24 个。旧账户升级自动补入新增站点，保留停用、删除、自定义设置和 Cookie。
- 漫画详情和封面本地缓存，详情页提前取即将阅读的一张正文图；阅读器优先加载当前页，异步解码，限制离屏图片驻留。
- 书目整理移到后台 Worker，减少启动时占用主线程；手机底栏首次测量交给浏览器排版后的尺寸通知。
- 保留已有漫画高分神作、名作推荐、书墙翻页和多源章节选择。

漫画网站的可用性和响应速度随网络、地区及源站变化，部分站点可能需要登录或人机验证。iPhone 包为未签名 IPA，继续使用 SideStore 签名覆盖安装，保留书架及记录。
